Notifikasi WhatsApp jatuh tempo KIR, Pajak & Service

Kirim pengingat WA otomatis untuk KIR/Pajak yang jatuh tempo dalam H-10 hari, atau Service Berkala yang tinggal 1000 km lagi

Tombol ini membuka WhatsApp (app/web) dengan pesan yang sudah otomatis berisi daftar kendaraan yang KIR/Pajak-nya H-10 hari atau sudah terlambat, dihitung langsung dari data terbaru di sistem ini — tinggal klik Kirim di WhatsApp. Karena halaman ini berjalan di browser (tanpa server), pesan hanya bisa dikirim saat sistem ini dibuka; untuk pengiriman otomatis 24 jam tanpa membuka aplikasi, gunakan setup otomatis penuh di panel di bawah ini.

Setup notifikasi WA otomatis penuh (tanpa perlu buka aplikasi ini)

Google Apps Script + WhatsApp Gateway (Fonnte) mengecek jatuh tempo setiap hari dan kirim WA sendiri, walau sistem ini sedang tidak dibuka

Data DO, Kendaraan, dan Maintenance sekarang sinkron real-time otomatis lewat Firebase antar semua perangkat — tidak perlu tombol atau centang apa pun lagi untuk itu.

1. Buat Google Sheet baru (boleh sheet baru khusus, terpisah dari sheet tarif).
2. Buka Extensions → Apps Script, hapus isi default, tempel kode di bawah ini.
3. Daftar gratis di fonnte.com, hubungkan nomor WA yang akan jadi pengirim, lalu salin Token-nya.
4. Di kode di bawah, ganti FONNTE_TOKEN dengan token Fonnte kamu, dan WA_TARGET dengan nomor WA tujuan (format 62xxx, bisa lebih dari satu nomor dipisah koma).
5. Klik Deploy → New deployment → tipe "Web app", akses "Anyone", lalu Deploy. Salin URL-nya (diakhiri /exec) ke kolom di atas.
6. Di editor Apps Script, klik ikon jam (Triggers) → Add Trigger → pilih function checkAndNotify, jenis "Time-driven" → "Day timer" → pilih jam pengecekan (mis. 07.00–08.00) → Save.
7. Kembali ke sistem ini, klik "Push data kendaraan ke Google Sheet sekarang" (atau centang push otomatis) supaya data KIR/Pajak terbaru selalu ada di Sheet tersebut. Mulai saat itu, Apps Script akan mengecek sendiri setiap hari dan kirim WA otomatis walau sistem ini tidak dibuka.
Opsional — tarik KM otomatis dari GPS Cartrack: isi CARTRACK_USERNAME dan CARTRACK_PASSWORD di kode (dari akun Cartrack Fleetweb Anda, menu API Settings), lalu tambah trigger kedua untuk function syncOdometerFromCartrack (mis. tiap 4 jam). Setelah itu buka tab Maintenance Perbaikan → panel Monitoring Service Berkala → klik "Tarik KM terbaru dari GPS" agar aplikasi ini ikut update KM-nya.

Database tarif ongkos per kota & jenis kendaraan

Atur harga angkut (Rp per kg) untuk tiap kombinasi jenis armada dan kota tujuan — dipakai otomatis untuk menghitung Pendapatan DO di Rekap Data begitu status DO diubah menjadi Selesai

Tarif belum tersinkron. Buka Pengaturan → Sinkronisasi Tarif.

1. Buat Google Sheet dengan 3 kolom: Armada (tronton / engkel / cdd / lainnya), Kota (kota tujuan, cth. Bandung) dan HargaPerKg (angka, Rupiah per kg).
2. Buka Extensions → Apps Script pada sheet tersebut, hapus isi default, lalu tempel kode di bawah ini.
3. Klik Deploy → New deployment → pilih tipe "Web app", akses "Anyone", lalu Deploy.
4. Salin URL Web App yang dihasilkan (diakhiri /exec) ke kolom di atas, lalu klik "Sinkronkan sekarang".

Database ongkos borongan

Daftar harga borongan per rute — tampilan disamakan persis dengan Google Sheet "MASTER ONGKOS BORONGAN", dan bisa disinkronkan otomatis. Hanya akun admin yang bisa mengatur sinkronisasi ini.

Data borongan belum tersinkron. Buka bagian "Cara membuat Web App" di bawah.

1. Buka Google Sheet Anda, pada tab/sheet MASTER ONGKOS BORONGAN PA LUAR (sheet yang sama seperti yang sudah Anda pakai selama ini).
2. Buka menu Extensions → Apps Script pada sheet tersebut, hapus isi default, lalu tempel kode di bawah ini.
3. Jika nama tab sheet Anda berbeda dari MASTER ONGKOS BORONGAN PA LUAR, ganti nilai SHEET_NAME di baris pertama kode sesuai nama tab Anda.
4. Klik Deploy → New deployment → pilih tipe "Web app", bagian "Who has access" pilih "Anyone", lalu Deploy.
5. Salin URL Web App yang dihasilkan (diakhiri /exec) ke kolom di atas, lalu klik "Simpan & sinkronkan sekarang".
6. Setelah itu, setiap Anda mengubah data di Google Sheet, klik "Sinkronkan sekarang" di sini (atau centang sinkron otomatis 5 menit) supaya sistem selalu menampilkan data terbaru — tidak perlu deploy ulang.
